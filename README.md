# Music Artist Shuffle Renamer

一款面向顺序播放 MP3 播放器的歌曲批量重命名工具。

程序会识别文件名中的歌手信息，将同一歌手的歌曲均匀分散到整张歌单中，然后添加 `0001__`、`0002__` 等编号前缀，从而控制歌曲的播放顺序。

A lightweight Python GUI tool that evenly distributes songs by artist and adds numbered filename prefixes for sequential-play MP3 players.

## 项目初衷

最开始，我只是想在家里的小音箱中给老人多放一些歌。我整理了大约 400 首歌曲，并把它们存进 U 盘。实际播放后，我发现这个音箱只能按照文件名顺序播放，没有随机播放功能。

由于歌曲文件通常按照歌手名称排列，同一位歌手的歌曲会集中在一起。播放时经常连续十几首都是同一个歌手，然后才轮到下一位。即使每首歌单独听都很好听，这样连续播放也很容易让人觉得重复。

年轻人遇到这种情况，可以直接使用手机上的随机播放功能。但很多老人使用的音箱功能比较简单，有些只能插入 U 盘后顺序播放。让老人重新学习手机软件或复杂的播放操作也不太现实。

于是我想到，能不能不更换音箱，也不改变老人的使用习惯，只在放歌之前把歌曲顺序处理好？

这个程序就是为了解决这个小问题而写的。它会读取文件名中的歌手信息，根据每位歌手的歌曲数量，把歌曲均匀分散到整张歌单中，然后添加 `0001__`、`0002__` 等数字前缀。音箱仍然按照文件名顺序播放，但实际听到的歌曲已经是不同歌手交叉排列的。

对老人来说，使用方式没有任何变化。他们仍然只需要插入 U 盘并打开音箱。歌曲顺序的处理全部在放入 U 盘之前完成。

这个项目起源于一个很普通的家庭场景，但我发现它也可能帮助其他使用老式 MP3、车载播放器、广场舞音箱或老人小音箱的人。它不需要更换设备，只需要运行一次程序，就能让原本单调的顺序播放听起来更自然。

## 主要功能

- 按歌手均匀分散歌曲
- 自动识别 `歌手 - 歌名` 文件名格式
- 支持包含多位合作歌手的歌曲
- 批量添加四位数播放顺序前缀
- 重复运行时自动替换旧前缀
- 自动保存 CSV 重命名记录
- 支持一键撤销最近一次重命名
- 采用临时文件名分阶段处理，减少文件名冲突
- 提供中文图形界面
- 不修改音频内容和音频标签
- 不需要安装第三方 Python 库

## 支持的音频格式

- MP3
- FLAC
- WAV
- M4A
- AAC
- OGG
- WMA
- APE

## 使用方法

### 方法一：双击运行

1. 安装 Python 3。
2. 下载 `music_artist_shuffle_renamer.py`。
3. 双击运行程序。
4. 选择存放歌曲的文件夹。
5. 点击“一键交叉乱序并重命名”。
6. 确认后等待处理完成。

### 方法二：命令行运行

```bash
python music_artist_shuffle_renamer.py
```

## 重命名示例

处理前：

```text
韩磊 - 走四方.mp3
周杰伦 - 晴天.mp3
韩磊 - 千古英雄浪淘沙.mp3
```

处理后：

```text
0001__周杰伦 - 晴天.mp3
0002__韩磊 - 走四方.mp3
0003__其他歌手 - 歌曲.mp3
0004__韩磊 - 千古英雄浪淘沙.mp3
```

实际顺序会根据文件夹中的歌手数量和歌曲数量自动计算。

## 排序方法

程序首先去除之前生成的编号前缀，然后根据文件名识别主要歌手。

对于每位歌手，程序会根据歌曲总数计算理想播放间隔，并生成多种候选排列。最后选择同一歌手分布最均匀的一种结果。

这种方式不仅可以避免同一歌手连续出现，也可以减少“同一歌手、其他歌手、同一歌手”的反复交替。

## 撤销重命名

每次重命名时，程序都会在歌曲文件夹中生成一份 CSV 恢复记录。

如果需要恢复原文件名，可以重新打开程序，然后点击“撤销最近一次重命名”。

请不要手动修改或删除恢复记录中的文件名信息。

## 注意事项

- 建议第一次使用时先复制少量歌曲进行测试。
- 程序只处理所选文件夹的当前层，不处理子文件夹。
- 程序只修改文件名，不修改音频内容。
- 如果某位歌手的歌曲占全部歌曲的一半以上，少量接近或连续出现可能无法完全避免。
- 部分 MP3 播放器需要重新扫描歌曲，或者重新插拔存储设备后才会显示新的顺序。
